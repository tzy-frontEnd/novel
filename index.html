每本书的章节、设定、范本各存各的,互不干扰。

这本书
写作偏好
设定

这段会原样交给模型。人物写清年龄、性格、说话方式,后面才不容易写崩人设。

长篇最容易在这里出错。把“绝对不能写错”的事放进来,每次生成都会带上。

范本与文风

把你喜欢的段落、自己的旧稿传上来,让模型学它的写法。建议用自己的稿子或已过版权期的作品;只学手法,不照抄句子。

连接 DeepSeek

到 platform.deepseek.com 注册,在「API keys」里创建一个。Key 只存在这台手机里,不会传到别处;不想用了回平台删掉即可。

低一些更稳、更像前文;高一些更放得开、也更容易跑偏。小说一般 1.1 到 1.3。

高级:接口地址

默认就是 DeepSeek 的地址。换成其他兼容 OpenAI 格式的接口时才动。

数据

备份文件不含 API Key。建议一周导一次,存到微信收藏或网盘。

把写作台放到手机桌面

iPhone:用 Safari 打开,点底部的「分享」,选「添加到主屏幕」。

Android:用 Chrome 打开,点右上角菜单,选「添加到主屏幕」。

从桌面图标打开时,浏览器给你分配的存储空间更稳定,不容易被系统回收。

这个网页是怎么工作的

页面在你手机浏览器里直接请求 DeepSeek 的接口,没有中间服务器。Key 只存在本机,正文也只存在本机。模型写出来的东西直接显示在页面里,不用等谁转发。
