这本书
写作偏好

可以随便填。想一段内换视角,就写“自由转换”,再在「本章要求」里说明从哪一段换、换成谁的口吻。

设定

这段会原样交给模型。人物写清年龄、性格、说话方式,后面才不容易写崩人设。

长篇最容易在这里出错。把“绝对不能写错”的事放进来,每次生成都会带上。

卡片库

一张卡讲一件事,每次生成都会带上。人物卡写清年龄、外貌、性格、说话习惯、和谁是什么关系,还可以挂形象图(最多 8 张)。图传上来后点「按图生成外貌」,会把长相写成一小段文字存进卡片——以后每次写作只带这段文字,不用反复发图,省钱也更稳。上传 .txt / .md 时,用「## 名字」当小标题就会拆成多张卡;文件里再用「# 人物」「# 世界观」「# 设定」「# 地点」分段,会自动归到对应分类。写作途中想补,回「正文」点「+ 设定卡」即可。

范本与文风

把你喜欢的段落、自己的旧稿传上来,让模型学它的写法。建议用自己的稿子或已过版权期的作品;只学手法,不照抄句子。

连接 DeepSeek

到 platform.deepseek.com 注册,在「API keys」里创建一个。Key 只存在这台手机里,不会传到别处;不想用了回平台删掉即可。

开思考时,模型先在内心打草稿再写,更稳但更慢更费。日常写正文选「关闭」;点「检查一致」前切到「高」或「最高」更准。

带得越多,笔感越连贯;太长会拖慢、也更贵。一般 2500–4000。

减少反复用同一个词和句式,0.2–0.4 比较自然;开思考时这项不生效。

低一些更稳、更像前文;高一些更放得开、也更容易跑偏,小说一般 1.1 到 1.3。注意:开了思考后 DeepSeek 会忽略这个参数,只有「思考关闭」时它才生效。

这是给模型的篇幅参考,不是硬限制。一次写太长容易啰嗦、重复,建议 2000 到 4000;更长的用「接着写」分几次完成。

高级:接口地址

默认就是 DeepSeek 的地址。换成其他兼容 OpenAI 格式的接口时才动。

多设备同步(可选)

把进度同步到你自己的一个 私有 GitHub 仓库里,手机和电脑打开同一个网址就能接着写,也能翻看之前写的所有章节。不配也照常能用,只是各设备各存各的。DeepSeek 的 Key 不参与同步,每台设备各填一次。

怎么建私有仓库和 Token

1. GitHub 右上角「+」→ New repository,名字填 novel-sync,选 Private,勾上 Add a README(这样就有 main 分支),Create repository。

2. 点头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。Repository access 选 Only select repositories,只勾 novel-sync;Repository permissions 里把 Contents 设为 Read and write。生成后复制 github_pat_ 开头的那串。

3. 把用户名、仓库名、Token 填到上面,点「立即同步」。另一台设备打开同一个网址,填一样的信息再点一次同步,那边的书架就会落进同一份进度。

Token 相当于一把只开这一个私有仓库的钥匙,只存在设备本机;不用了回 GitHub 删掉即可。两台设备同时改同一本书时,以最后保存的那一份为准,所以换设备前先点一下同步。

数据

备份文件不含 API Key。建议一周导一次,存到微信收藏或网盘。

把写作台放到手机桌面

iPhone:用 Safari 打开,点底部的「分享」,选「添加到主屏幕」。

Android:用 Chrome 打开,点右上角菜单,选「添加到主屏幕」。

从桌面图标打开时,浏览器给你分配的存储空间更稳定,不容易被系统回收。

这个网页是怎么工作的

页面在你手机浏览器里直接请求 DeepSeek 的接口,没有中间服务器。Key 只存在本机,正文也只存在本机。模型写出来的东西直接显示在页面里,不用等谁转发。
